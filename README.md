## Dokumentation

Im Tab Übersicht werden alle Bestellungen angezeigt, bei denen der Status auf P (Pending) steht.

Im Tab Status zurücksetzen kann über die Eingabe der Bestellnummer der cAbgeholt Status in der Datenbank zurückgesetzt werden. Dazu einfach die Bestellnummer in das Feld eintragen und danach über den Button bestätigen. Es können nur Bestellungen mit dem Status Pending erneut an die Wawi gesendet werden. Um Fehler auszuschließen, wird nach Eingabe der Bestellnummer der Status geprüft.
